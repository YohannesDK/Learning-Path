## Learning-Path

### User Stories
- As a bouvet employee, i would like to have a place where i can go and find **concrete path** 
  or **structure** getting better at **something specific**, related to my work.

- As a bouvet employee, a place where i can find inspiration on **subjects** / **topics** to learn for my domain.

- As a bouvet employee, i would like to keep track of my progress on the path i am on.

- As a bouvet employee, i would like to get assistance from an AI, given my background (integrate cv) and something i want, 
  to create a learning path.

- As a bouvet employee, i would like a overview over where i can find the information related to a specific subject / topic / node. 


- As a bouvet employee, i would like to have information how my colleague rate the different topics <- subjects <- paths <- node (aggregated).

- As a bouvet "learning path" creator, i would like to be able to created nodes, connect to path, add courses...

- As a bouvet "learning path" owner, i would like to have se statistics about various things.
